# Enso documentation

This site documents Enso, the visual environment for preparing and analysing
data. The guides explain how to use the IDE; the [Components](./api/index.md)
reference describes every component of the standard libraries.

## Guides

- [Getting started](./getting-started/index.md): create a project, add and
  connect components, read a result and get help.
- [Installing and updating](./installing-and-updating/index.md): download Enso,
  install it on Windows, macOS or Linux, and keep it up to date.
- [Sample projects](./samples/index.md): the example projects that come with
  Enso, and how to open them.
- [Versions of your projects](./local-versioning/index.md): save, compare and
  restore versions of a project, and organise projects with labels.
- [Secrets](./secrets/index.md): keep passwords and keys out of your projects
  and use them in a workflow.
- [Engine logs](./engine-logs/index.md): read what the engine is doing, and send
  it with a bug report.

The developer documentation (the engine, the language server, building Enso) is
in the project's [wiki](https://github.com/jdunkerley/enso/wiki).
