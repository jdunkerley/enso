# std-bits/yxdb

`Standard.YXDB`'s Java: `org.enso.yxdb.YXDBReader`, which reads an Alteryx
`.yxdb` file into a Java table and converts spatial objects to GeoJSON, packaged
as `std-yxdb.jar` in the library's `polyglot/java` together with the
`yxdb-java` library it wraps. `std-base` and `std-table` are `provided`. The
format itself is Enso, in `distribution/lib/Standard/YXDB/`.
